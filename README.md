# Latis

RAW 照片 → LUT → 带 ICC 的成品图。免安装。

![screenshot](docs/screenshot.png)

---

## 下载

到 [Releases](../../releases) 下载最新的 `Latis-1.0.zip`，解压到任意位置，双击 `Latis.exe`。

不需要装 Python，不需要管理员权限。配置和 LUT 都存在 exe 旁边，删掉文件夹就是卸载。

**首次运行可能被 SmartScreen 拦**：程序没有代码签名。右键 exe → 属性 → 勾「解除锁定」→ 确定即可。哈希校验见 [免责声明.txt](免责声明.txt)。

---

## 快速开始

1. 点左上 **导入 ▾** → 添加文件 / 添加文件夹
2. 右边栏点缩略图切换照片
3. 左栏调：输出到哪、要不要 LUT、LUT 用哪个
4. 点 **导出…** → 选位置、格式、范围

## 特性

**① 原厂 RAW 直接进**
基于 rawpy（LibRaw）解码，覆盖主流相机厂商的 RAW 与专有压缩格式，不需要先转 DNG。

**② 全程 32 位**
解码后所有运算在 float32 线性域完成，多级 CST 串联不累积量化误差；只在最后一步量化到所选位深。

**③ LUT 不挑输入空间**
每份 LUT 只需声明输入空间（V-Log / S-Log3 / LogC / ACES…），内置 CST 负责把源转过去。
不同输入空间的 LUT 可以混用，切换不用换素材。

**④ 色彩空间全程可见**
源 → LUT 输入 → LUT 输出 → 文件目标，四段都写在界面上，没有藏在后台的隐式转换。

LUT 输出空间是 LUT 的属性：从文件夹自动读取并标注来源；未声明时落到明确的下限（Rec.709），
而不是沿用上一个 LUT 的设置。

**⑤ 导出的文件是自洽的**
文件里的色彩空间标记和像素值对得上。别人用任何带色彩管理的软件打开，看到的颜色和导出一致。

## 左栏三个空间

从上到下就是管线的顺序：

```
源  ──────────▶  LUT 输入  ──LUT──▶  LUT 输出  ──────────▶  导出到
ACE S2065-1                V-Gamut       Rec.709              sRGB
或 Log 编码                V-Log         Gamma 2.4            sRGB
```

- **源**：相机给的，一般不用改
- **LUT 输入 / 输出**：这份 LUT 期望喂什么、吐出来是什么
- **导出到**：成品文件要什么空间

**LUT 输出空间要看 LUT 自己的说明，不要看你想要的成品空间。** 两者填错，画面会整体偏色。

## LUT 放哪

```
lut/
└── V-Gamut-V-Log/          第一层：这份 LUT 的输入
    └── sRGB-sRGB/          第二层：这份 LUT 的输出
        └── Arri/
            └── ARRI_LogC2.cube
```

两层文件夹名都写成 `色域-曲线`（`V-Gamut-V-Log`、`Rec.709-Gamma 2.4`、`sRGB-sRGB` …）。

把 .cube 拖进对应文件夹，程序下次启动就认得。也可以点左栏 **导入 .cube**，会按当前下拉设置自动放到位。

## 限制

- Log / Linear 编码的照片，预览里**不能**正确显示颜色。程序会在预览区提示，只做参考。
- HDR 和 Windows 高级颜色没做。
- 屏幕实际发出的光是否标准，需要色度计验证，程序管不了。
